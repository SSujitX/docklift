# Profile Management

Manage your personal account information and password from the Docklift panel.

## Update profile

1. Click your name at the bottom of the left sidebar (or open the account menu)
2. Select **Profile Settings**
3. Update your full name and email
4. Click **Update Profile**

## Change password

1. Open **Profile Settings**
2. Scroll to **Security**
3. Enter your **Current Password**
4. Enter and confirm the **New Password**
5. Click **Change Password**

Choose a strong unique password. The same password is required again for step-up actions (restore, terminal host ops, purge, reboot, and similar).

## Lost password

If you cannot sign in, use the emergency reset on the server — see [Reset Password](./reset-password.md). That script cannot be run from the web dashboard alone.
